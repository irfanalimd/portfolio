# irfanali.me

Personal site of Irfan Ali. Plain HTML, CSS and JS with no build step, hosted on GitHub Pages.

- `index.html` is the whole page. Edit the text there.
- `assets/site.css` holds the styles (light and dark themes). `assets/site.js` runs the hero's SLAM simulation, the theme toggle, scroll effects and project hover previews.
- `assets/img/` holds the photos. The portrait is 4:5 (800×1000) and the lab clips are animated WebP.
- `assets/og.png` is the link-preview image (1200×630).
- `CNAME` sets the custom domain.

Preview locally with `python3 -m http.server` and open http://localhost:8000.
